Marginwise solution build kit

One page per solution: what it does, how we build it, the prompt to build or customise it in Claude Code, a demo video script, a pricing proposal, and a case study template.

Where the code lives: - marginwise/solutions/leak-audit/ is the store audit crawler (Node + Playwright + axe-core). - marginwise/solutions/agents/ holds the AI agents. Each one has solutions/<name>/prompt.md (system prompt), tools.json (tool definitions), handlers.py (integrations, mocked for tests) and fixtures/. The shared runner is in core/.

How to read "Build here": - Here. Builds and tests fully in this repo with fixtures. Runs live once an ANTHROPIC_API_KEY is set. - Client access. Needs the client's admin, API or phone credentials to go live. We build and test against fixtures first, then connect. - Partner. Needs a third party: a law firm, a certified e-invoicing provider, or a telephony provider.

AI model defaults: - claude-sonnet-5-5 for conversations and reasoning. - claude-haiku-5-5 for high-volume classification.

Every agent that changes money, prices, orders or invoices goes through human approval.
